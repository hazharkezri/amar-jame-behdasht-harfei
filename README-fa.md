# سامانه‌ی آمار بهداشت حرفه‌ای — دانشگاه علوم پزشکی ارومیه

بدون وابستگی خارجی؛ فقط Node.js ۲۲٫۵ یا بالاتر.

## راه‌اندازی
1. `cp .env.example .env` و `APP_SECRET` را با `openssl rand -hex 32` پر کنید (از آن پشتیبان جدا بگیرید).
2. مسئول ستاد: `node --no-warnings scripts/create-root.js <کدملی> "<نام>" <ایمیل@...ac.ir>` — رمز موقت و کلید احراز هویت چاپ می‌شود؛ کلید را در برنامه‌ی Authenticator وارد کنید.
3. ۱۹ شهرستان: `node --no-warnings scripts/seed-urmia.js`
4. اجرا: `docker compose -f deploy/docker-compose.yml up -d` (گواهی TLS در `deploy/certs/fullchain.pem` و `privkey.pem`) یا `deploy/amar.service` با systemd پشت nginx. **بدون HTTPS اجرا نکنید.**
   - **استثنا: شبکه‌ی داخلی دانشگاه.** اگر سامانه فقط داخل شبکه‌ی دانشگاه با آدرس داخلی سرو می‌شود، راهنمای اختصاصی `deploy/INSTALL-intranet-fa.md` را بخوانید (با `COOKIE_SECURE=0` روی HTTP هم کار می‌کند؛ فقط قابلیت آفلاین/PWA غیرفعال می‌ماند).
5. دوره‌ی آماری را از «مدیریت ستاد» بسازید.
6. فایل ۲ (در صورت نیاز): از «مدیریت ستاد ← درون‌ریزی فایل ۲» یا `scripts/import-file2.js`.

## روال کار
مسئول ستاد کدملی مسئولان شهرستان‌ها را (تکی یا گروهی با اکسل) ثبت می‌کند ← آن‌ها ثبت‌نام و TOTP را فعال می‌کنند ← مسئول بالادستی تأیید می‌کند ← مسئول شهرستان کدملی کارشناسان/مراکز را ثبت و تأیید می‌کند. کارشناس آمار را وارد، و «ارسال» می‌کند؛ مسئول بالاتر تأیید (قفل) یا برگشت (با علت) می‌دهد.

## نگهداری
- پشتیبان: `deploy/backup.sh` با cron. تست: `npm test`.
- گم‌شدن گوشی کاربر: «کاربران ← بازنشانی».
- محدودیت‌ها: SQLite برای ده‌ها هزار ردیف و ده‌ها کاربر همزمان مناسب است؛ برای کل کشور باید به PostgreSQL مهاجرت شود. ارسال پیامک/ایمیل و اتصال به سامانه‌ی استعلام هویت/استخدام وجود ندارد. ممیزی امنیتی مستقل انجام نشده؛ پیش از بهره‌برداری رسمی انجام شود. آفلاین فقط برای صفحه‌ی بازشده، صف ورود آمار است.
- **سطح کشوری:** create-root.js را با آرگومان پنجم `country` اجرا کنید (root type country)، سپس `node scripts/seed-iran.js` (۶۵ دانشگاه/دانشکده + ۴۳۵ شهرستان) و `node scripts/seed-periods.js` (دوره‌های شش‌ماهه و سالیانه). مراکز خدمات جامع سلامت (شهری و روستایی) را مسئول هر شهرستان از «مدیریت ستاد ← ساختار واحدها» یا بارگذاری گروهی (اکسل) اضافه می‌کند — فهرست رسمی مراکز در پورتال وزارت بهداشت (behdasht.gov.ir) موجود است و می‌توان آن را به قالب اکسل تبدیل و بارگذاری کرد. کارشناسان تمام سطوح (کشور، دانشگاه، شهرستان، مرکز) می‌توانند داده را مستقیم وارد کنند؛ مدیران می‌توانند واحد هدف را در صفحه‌ی «ورود آمار» انتخاب کنند.
